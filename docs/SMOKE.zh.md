## 已知限制 / 待补

- 100%/150% 缩放需第二台机器实测；已从根因上覆盖 Host antialiased 与 SimSun 回退。
- 语音转写依赖官方实验语音 Bundle 与本地模型缓存；未缓存时会打开官方准备引导。
- 独立滑条插件与合并版同时启用时，合并版在启动后检测并跳过；若运行中再启用独立插件，可能短暂双滑条，重载后恢复。
- 主题仍依赖 DSH CSS Module 选择器；宿主升级后若选择器变化，HUD/滑条/语音可能降级但不影响会话。
